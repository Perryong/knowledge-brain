# AI Engineer Credentialing Paths 2026

**Angle 5** — what actually moves hiring outcomes vs noise.

## The hierarchy (signal, high → low)
1. **Portfolio / shipped work** — the dominant signal. Cleanest 2026 profiles: a few public GitHub repos with a **working end-to-end project**, 1–2 technique writeups, a Hugging Face/Kaggle profile with published artifacts. Confidence: high (consistent across sources). **No certification replaces portfolio projects.**
2. **Open-source contribution** — demonstrates real collaboration + code quality; higher signal than any cert. Confidence: medium.
3. **Certification (as tiebreaker)** — [[AWS ML Certification|AWS MLA-C01]] (the MLS-C01 is retired — avoid) or Google Professional ML Engineer. A tiebreaker, not a hiring driver; worth it if anchored to that cloud. Confidence: medium.

## Singapore-specific
- **[[AI Singapore AIAP]]** — highest-signal SG path: government-funded apprenticeship, real projects, >90% placement. Best fit for converting 1–3 yrs experience into placement-grade work. Confidence: medium.
- **TeSA (TechSkills Accelerator)** — SkillsFuture/IMDA initiative; TeSA-affiliated cloud-ML and DL certifications are recognised by major SG employers. Confidence: medium.
- **SkillsFuture** — subsidy layer funding the above rather than a credential itself. Confidence: medium.

## Verdict
Certs are **noise on their own, signal as a layer** on top of shipped work. For SG mid-level → senior, AIAP + one AWS cert + a strong GitHub end-to-end project is the highest-leverage combination. Global: portfolio + open-source + one cloud cert.

> [!gap] "Certs correlate with ~20–25% pay bumps" appears in single aggregator sources — correlation, not causation. Do not chase certs for the raw number.
