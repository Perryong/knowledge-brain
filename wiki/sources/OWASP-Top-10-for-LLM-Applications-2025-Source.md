# OWASP Top 10 for LLM Applications 2025 (source)

Primary, community-driven security standard for LLM applications, maintained by the OWASP GenAI Security Project. The "2025" edition document is dated **2024-11-17**. Confidence: **high** (authoritative primary source).

The landing page exposes the list via a downloadable PDF; the item names below are corroborated across multiple independent 2026 security write-ups (Evidently AI, Oligo, Aembit) that summarize the same edition.

The 2025 edition reworks the 2023 list to reflect real-world incidents and the rise of **agentic AI**: it adds new categories (system-prompt leakage, unbounded consumption), promotes sensitive-information disclosure to #2, and keeps prompt injection at #1 for the second edition running.

See [[OWASP Top 10 for LLM Applications 2025]] for the enumerated LLM01–LLM10 list applied to the engineering checklist.
